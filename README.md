# RoboCoffee

RoboCoffee is an autonomous mobile robotics project focused on the development, simulation, and implementation of a differential-drive robot designed for coffee delivery applications.

The project integrates inverse kinematic modeling, motion control, simulation, and real-world robot testing. Development includes trajectory and position control in simulation environments such as Webots, followed by implementation and validation using the OAK9 mobile robot platform.

## Project Objectives

The main objectives of this project are to:

* Develop and validate the kinematic model of a differential-drive mobile robot.
* Implement position and trajectory control algorithms.
* Simulate robot motion and controller performance in Webots.
* Transfer the developed control strategies from simulation to the physical OAK9 robot.
* Evaluate robot behavior, positioning accuracy, stability, and motion performance.
* Explore the application of autonomous mobile robotics for coffee delivery and service environments.
